Paladin Replay Launcher — try it

A local page for checking the launcher end to end. Nothing here is uploaded anywhere.

First time only

  1. Run PaladinReplayLauncher.exe --install once, so paladin:// links work.
  2. Run PaladinReplayLauncher.exe --doctor to check Steam and Age of Empires IV were found.
  3. Close Age of Empires IV before pressing the button below.

Open a replay

Both are given because the replay is stored against whichever player had match history sharing switched on. The launcher tries each in turn, so it does not matter which order you put them in.

What should happen

  • Your browser asks once whether to open Paladin Replay Launcher — allow it.
  • A console window appears: replay downloaded, settings snapshot created, replay placed.
  • Steam launches Age of Empires IV into the replay. Leave the console open.
  • An authentication error in Age of Empires IV at the start is normal in replay mode.
  • Quit the game. The console reports what changed and restores anything real.
  • "no settings were changed" is the expected result — timestamps and run counters are recognised as bookkeeping and deliberately left alone.

If nothing happens when you press it

  • The link handler is probably not registered. Run --install once.
  • --doctor then reports where paladin:// points.
  • Any ordinary run repairs a missing or broken registration by itself.
  • If the replay 404s, Microsoft no longer has one for that match. Try a more recent game.
